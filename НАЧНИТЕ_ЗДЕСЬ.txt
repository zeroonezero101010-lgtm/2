ПОРТФОЛИО С ОБЛАЧНОЙ АДМИН-ПАНЕЛЬЮ

Что получится:
- публичный сайт: /
- панель управления: /admin/
- клиент входит по своему email и паролю, меняет названия, добавляет/удаляет проекты и изображения, меняет порядок.
- изменения сохраняются в Supabase и сразу видны посетителям. Повторно загружать сайт при каждой правке не нужно.

ВАЖНО: это комплект для настройки, а не подключение к вашему аккаунту автоматически. Нужна одноразовая настройка Supabase.

ШАГ 1. Создайте облачную базу
1. Зарегистрируйтесь на https://supabase.com и создайте новый Project.
2. Откройте SQL Editor → New query.
3. Скопируйте весь файл supabase-setup.sql, вставьте в редактор и нажмите Run.

ШАГ 2. Создайте логин администратора
1. В Supabase откройте Authentication → Users → Add user.
2. Создайте email и пароль клиента (или свой, пока настраиваете).
3. Скопируйте UUID созданного пользователя.
4. В SQL Editor выполните команду, подставив UUID:
   insert into public.admins(user_id) values ('ВСТАВЬТЕ-UUID');
   Если будете выполнять повторно, можно использовать:
   insert into public.admins(user_id) values ('ВСТАВЬТЕ-UUID') on conflict do nothing;

ШАГ 3. Подключите сайт к Supabase
1. Supabase → Project Settings → API. Скопируйте Project URL и publishable/anon key.
2. Откройте supabase-config.js и замените два текста-заполнителя.
   Вставлять можно только publishable/anon key. НИКОГДА не вставляйте secret/service_role key в сайт.
3. Сохраните файл.

ШАГ 4. Загрузите комплект на Netlify
1. Скачайте резервную копию текущего сайта.
2. Распакуйте этот ZIP. Загрузите содержимое папки на Netlify тем же способом, которым вы обновляли сайт. Если сайт связан с GitHub, разместите файлы в репозитории, который разворачивает этот сайт.
3. Убедитесь, что index.html, supabase-config.js, папка admin и папка assets находятся в корне сайта.
4. Откройте адрес сайта /admin/ и войдите по email и паролю, созданным в Supabase.

ШАГ 5. Добавьте исходные работы
Публичная страница теперь получает список работ из Supabase. Для первого заполнения войдите в /admin/, нажмите «Новый проект», задайте название, затем загрузите изображения из assets/project-1, assets/project-2 и assets/project-3. Сохраните названия по своему усмотрению. Старые файлы нужны для первого переноса и могут остаться на сайте.

КАК ПОЛЬЗОВАТЬСЯ ПОТОМ
- Откройте /admin/ и войдите.
- «Новый проект» создаёт проект.
- «Название» меняет имя проекта.
- «Добавить изображения в выбранный проект» загружает новые файлы.
- стрелки рядом с проектами/миниатюрами меняют порядок.
- крестик удаляет изображение; «Удалить» удаляет проект.
- все изменения сразу отражаются на публичном сайте; публикация статических файлов повторно не нужна.

БЕЗОПАСНОСТЬ
- Никому не передавайте пароль от своего Supabase/Netlify аккаунта.
- Клиенту создавайте отдельного пользователя Supabase и добавляйте его UUID в public.admins. Для одного сайта не давайте клиенту доступ к чужим проектам Supabase.
- Доступ к данным на сервере защищён RLS; одного скрытия страницы /admin/ недостаточно.
- При утрате доступа администратор Supabase может сбросить пароль.
